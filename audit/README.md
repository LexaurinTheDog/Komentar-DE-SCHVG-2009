# Reproduktion der Extraktion

Für einen isolierten Neuaufbau `_parse.py` in ein neues Arbeitsverzeichnis kopieren und daneben das Verzeichnis `sources/` aus dem Repository bereitstellen. Dort den Parser ausführen. Die gesicherte Originaldatei `official.xml` ist die Eingabe; `units.jsonl` und `canonical.md` werden mechanisch erzeugt. Das hier beigelegte `units.jsonl` dokumentiert das verwendete Ergebnis. Nicht im fertigen Repository ausführen, wenn dessen Dateistand erhalten bleiben soll.
